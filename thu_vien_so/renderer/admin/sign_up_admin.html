Tạo Backup

Xuất toàn bộ dữ liệu (database, file đính kèm, hash, embedding) ra file .zip.

  • Sáng kiến, tác giả, giải thưởng
  • File PDF, ảnh, video đã upload
  • SHA-256, SimHash, Embedding vector

Phục hồi Backup

Chọn file .zip để phục hồi. Dữ liệu hiện tại sẽ được thay thế hoàn toàn.

Hành động này không thể hoàn tác. Hệ thống sẽ tự tạo bản dự phòng trước khi restore.
